# Vermity Backend

:warning: This repo is under heavy construction :warning:

This project features the server side code that will allow you to manage your rentable property
and most importantly the automatic creation of **Operating Expense Statements**

It is designed as a REST API returning and accepting JSON for given endpoints. 
Build your own or use the latter to come frontend. The frontend project can be found [here](https://github.com/Drizein/vermity-frontend)


## Features are and will be

- Creating an account
- Creating new houses including flats
- Add costs like cold rent, reoccurring costs (garden work, trash removal, etc.)
- Describe your rentable object with number of rooms, total square meter, etc.
- Add meters like gas or water to your object and/or flat, if your tenants don't manage them themselves
- Track when tenants move in and out
- Create yearly or on demand **Operating Expense Statements** as PDF
- *And many more to come....*
